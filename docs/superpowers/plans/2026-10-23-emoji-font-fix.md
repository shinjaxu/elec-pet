# 对话气泡 Emoji 缺字修复

已在真实 Windows Player 的合成气泡中复现方框，协议对原始 Emoji 与 JSON 转义代理对均能正确还原。编辑器中同一内容能显示彩色 Emoji；当前 Unity 6 编辑器额外加载 Emoji 回退资源，而 Player 的 IMGUI 运行时字体设置未配置该列表。

1. 保留含中文、笑脸、小龙、变体选择符和复合表情的渲染样本，新增真实 Player 颜色像素检查。验证：原程序确实缺少笑脸色彩，测试失败。
2. 为当前 Unity IMGUI 运行时设置注册系统 Segoe UI Emoji 动态字体回退，补齐官方彩色着色器与系统字体合字；气泡宽度向上取整，避免行尾贴边字形在实际绘制时额外换行。验证：真实 Player 字形检查通过，目视检查 100%/150% 合成图，并释放字体资源。
3. 完整回归、构建 Windows 并另存便携包。验证：既有功能测试通过，包内程序集与新构建一致，完整性检查通过。

只修复字体渲染，不改变模型内容或删除表情。当前 Unity 未公开 IMGUI 运行时 TextSettings 和默认合字列表入口，使用两处内部入口反射；未来升级 Unity 时以 Player 渲染回归检查这些兼容点。

底部溢出曾以实际 Player 图像复现：测量宽度 218.22，文本末端 218.21，实际绘制多出一行。仅将宽度向上取整后，原失败的颜色像素及底部留白检查通过；最终保留原有 CalcHeight 测量，移除试验性的 TextCore 网格与光标测量代码。

最终完成：Windows Player 3/3、EditMode 78/78 通过，正式构建成功；另存 `Builds/Portable/ElecPet-Portable-Emoji.exe`，归档完整性与 155 个包内文件 SHA256 比对均通过。详细证据和包校验值见 `docs/verification.md`。
