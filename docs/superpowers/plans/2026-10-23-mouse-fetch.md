# 鼠标捡球互动实施计划

**Goal:** 靠近伏低追视，快速甩动后停下生成球，奔跑拾取并持续追随鼠标，接近后锁定落点，螺旋飞行两圈并放球消失。
**Architecture:** Core 独立状态机负责手势和动作时序；Controller 编排安全坐标与互斥；PrototypePet 复用叼持并补充蓄势和振翼。
**Tech Stack:** Unity、C#、现有独立检查脚本。

用户已明确要求直接实现。范围、速度与持续时间由实现选择：近距 175 像素，快速甩动至少 90 像素且峰值 850 像素/秒，停稳 0.12 秒生成球；接近 75 像素锁定落点，飞行 2.4 秒。
