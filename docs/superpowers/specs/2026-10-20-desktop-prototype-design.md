# Windows 3D 桌宠：第一阶段设计

依据：聊天 01a15873-6967-7d72-a442-82e2437f0762 的最终总结。用户已明确要求按总结开始实现。

## 本轮目标

交付可导入 Unity 的 Windows x64 技术原型。一个几何体临时小兽可注视鼠标、被拖拽、沿主屏幕工作区四边移动、靠近桌面图标。支持暂停、隐藏、恢复与退出。仅读取图标位置，不打开、不移动图标。

## 技术与边界

- Unity 6000.6.6f1、C#、内置渲染管线，Mono x64；按用户实际安装版本调整。版本号及 revision 依据 Unity 官方版本页核对。
- 用 Editor 菜单生成启动场景和构建配置；运行时生成临时模型，不依赖外部美术资源。
- 独立 C# Core 处理工作区、屏幕坐标转换和巡游/拖拽/归边。Unity 负责模型、碰撞命中、输入和画面。
- Windows 原生窗口使用 DWM、Direct3D 11、BitBlt 交换链、置顶和禁止激活。只在鼠标命中模型时接收输入，拖拽期间保持捕获。
- 主屏幕工作区排除任务栏。桌面图标通过 Shell 的 IFolderView 读取并映射到窗口像素；刷新失败时清空旧目标，继续巡游。
- 全局快捷键提供隐藏后的恢复与紧急退出。无后台服务、无联网、无开机启动。
- 全部新增代码注释使用中文。成长、旅行、随机物种、SQLite 和正式模型均属于后续里程碑。

## 验收

自动测试覆盖工作区偏移、纵轴翻转、四边跨角、距离回绕、极小区域、暂停、拖拽归边及分辨率变化。Windows 实机检查透明背景、桌面点击穿透、不抢焦点、图标只读及隐藏恢复。记录测试条件与未验证项。

## 环境限制

首次交付时未安装 Unity Editor，仅通过系统 C# 编译器验证独立逻辑与 Windows 适配层。用户随后安装 Unity 6000.6.6f1，已迁移项目并开始使用实际 Editor 验证，最新结果见 docs/verification.md。透明窗口仍需单独实机验收。
