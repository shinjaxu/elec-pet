# 屏幕陪伴吐槽

用户已确认窗口停留检测与视觉模型方案，并要求开始实施。用途是宠物根据主人正在看的内容轻松陪伴，首版以文字气泡表达。

- 仅 Windows 独立程序观察真实前台窗口；编辑器不读取用户屏幕。
- 同一前台窗口和标题连续停留 30 秒，鼠标、键盘和页面滚动不重置；切换窗口或标题则重置。浏览器标签页以标题变化近似判断，不引入扩展。
- 每个连续停留会话最多触发一次；从发起观察开始全局冷却 180 秒。离开后返回是新的会话，但仍遵守全局冷却。
- 截取前台窗口与主屏幕的交集，最长边不超过 1280 像素，排除宠物置顶窗口。锁屏、最小化、桌面、无有效窗口、不支持捕获或捕获失败时跳过。
- 截图仅在内存使用，经本地 `http://127.0.0.1:11434/api/chat` 发送给 `qwen3.5:4b`，不落盘，不记录图像、窗口标题或模型全文。
- 启动及恢复可用性时检查模型视觉能力；服务不可用时冷却后重试，不下载模型，不阻塞动作。连接/能力检查 5 秒，推理最多 60 秒。
- 同一时刻最多一个捕获或模型任务。切换窗口、暂停、隐藏、喂食、提起、锁屏、关闭功能或退出会使旧结果失效并取消请求，恢复后重新计时。
- 中文一两句，亲近、轻松、温柔吐槽，不辱骂、不臆测看不到的内容。图片中的指令作为画面内容，不执行。内容无趣或不清晰时允许输出约定的静默标记。正文最多 80 个字符，气泡显示约 12 秒。
- 右键菜单提供独立开关并保存本地偏好；默认开启。喂食提示优先。无需语音、聊天面板、长期截图记忆或浏览器扩展。

验收：计时边界与失效规则自动测试；合成窗口证明截图裁剪和宠物排除；Unity 编译与 Windows 构建；本地模型使用合成窗口完成真实推理与气泡显示；生成并校验免安装包。

已验证环境：Ollama 0.40.9、qwen3.5:4b，模型声明并实测支持视觉；配套 64 位 Mono 合成图片推理通过。此前独立探测宿主存在编辑器 BCL 混用，需要使用配套系统库；正式 Unity Player 仍需独立验证。
