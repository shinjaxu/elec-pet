# 陪伴气泡视觉优化

用户认为当前弹窗太丑，并明确选择“奶油白，温暖轻盈”。采用暖白圆角气泡、深灰左对齐正文、少量鼠尾草绿点缀、小尾巴和柔和阴影；短文本收窄，长文本自然换行。轻微淡入和上浮，结束前柔和淡出，减少突兀感。

现状是陪伴文字复用喂食提示的深色背景、15 像素居中文字和固定 340 宽。替代方案为保持深色但改善排版，或像素风；用户选择暖白，因此仅为陪伴气泡新增独立绘制类，喂食提示保留现状。

沿用 Unity IMGUI，不新增第三方资源或依赖。气泡优先位于宠物上方，顶部空间不足时移到下方；限制在屏幕边距内，尾巴朝向宠物。使用 Windows 窗口 DPI 调整显示大小；预览覆盖 100%、125%、150%。不修改截图、模型、触发/取消规则、显示时长或鼠标穿透行为。

验收以真正的 IMGUI 渲染图为主，覆盖短句、80 字长句、四角及 DPI 缩放；运行既有测试，重新构建并校验免安装包。
