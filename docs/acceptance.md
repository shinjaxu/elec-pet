# Windows 桌面技术原型验收

以下条目必须使用真实 Windows 构建检查。独立 C# 测试通过不能代替这些条目。

## 屏幕陪伴

- [ ] 同一前台窗口及标题停留不足 30 秒不截图，满 30 秒至多回复一次；继续停留不重复，跨窗口遵守 3 分钟冷却。
- [ ] 切换窗口、快速切走再切回、切换标题不同的浏览器标签页后重新计时；推理期间切换不展示旧回复。标题相同的标签页属于已知识别限制。
- [ ] 暂停、隐藏、喂食、提起、锁屏、独立关闭开关后不显示旧气泡，恢复后重新检查模型和计时；重启保留开关偏好。
- [ ] 主屏部分越界窗口只截主屏交集，副屏窗口不触发；分别在 100%、125%、150% 缩放下确认文字方向正确，截图不含宠物或气泡。
- [ ] 黑图和受保护窗口安静跳过，旧系统缺少截图排除能力时停止观察；截图不落盘，日志无窗口标题、截图内容和模型全文。
- [ ] 停止 Ollama 或模型缺失时菜单显示未就绪，动作保持流畅且 3 分钟内不密集重试；服务恢复后可继续观察。
- [ ] 气泡靠近宠物且在屏幕内，长回复可读，12 秒后消失；喂食提示优先，气泡不抢键盘焦点、不拦截桌面点击。

## 运行条件

记录 Windows 版本、Unity 版本、显卡及驱动、各屏幕分辨率、排列位置、缩放比例、任务栏位置。分别在 100%、125%、150% 缩放下检查。活动范围按各屏幕实际工作区约束，外沿保留宠物安全距离，相接屏幕的共享范围允许跨越。

## 检查步骤

- [ ] 导入工程没有编译错误；生成场景后编辑器预览可看到临时小兽。
- [ ] Windows x64 构建成功；运行后背景透明，没有黑底或灰色遮罩。
- [ ] 在其他应用输入文字时，宠物移动、注视、点击与拖拽均不抢走键盘焦点。单独检查启动瞬间是否激活；启动阶段 Unity 的窗口创建尚需实测。
- [ ] 在远离宠物的透明区域单击、双击、框选图标和拖拽桌面文件，行为正常。
- [ ] 鼠标从透明区快速移入宠物并立即按下，检查按帧切换穿透造成的竞态；不能发生对桌面图标的意外双击或拖动。当前实现未经过此项验收。
- [ ] 鼠标靠近时小兽注视并短距离追逐；轻点产生反馈；在身体上移动鼠标产生抚摸反馈。
- [ ] 跟随到最近距离后保持鼠标静止，宠物停止位移，不在追逐和归边间抽搐；扑食落地后同样停稳。鼠标移远后恢复归边，触碰和提起仍能打断跟随。
- [ ] 按住并移动小兽，可以从主屏拖到副屏并松手继续活动；分别检查副屏位于左侧、右侧和上方时的点击、抚摸、右键菜单和拖放，坐标没有偏移。
- [ ] 两屏错位或分辨率不同时，拖拽、追逐、扑跃、巡游和松手归边均不会进入无屏幕空隙或任务栏，身体在屏幕外沿保持安全距离；共享接缝可连续拖过。
- [ ] 在头部缓慢移动鼠标，观察眯眼、抬头和尾巴反馈；触碰翅膀或尾巴时反应有所区别。快速掠过不持续触发抚摸。
- [ ] 每次间隔不超过 1.5 秒，连续轻点三次，宠物躲闪约 2.8 秒后恢复；间隔超过 1.5 秒的点击不累积为连续戳弄。
- [ ] 拖动提起时爪子悬空轻晃；松手后先整理约 1.6 秒，再恢复活动。拖拽过程中图标刷新不打断提起。
- [ ] 连续观察两分钟，出现歪头伸爪、伸懒腰、整理翅膀或点头瞌睡；随机片段不连续重复，触碰可打断片段。
- [ ] 外形可辨认为无牙仔：宽扁黑色头部、绿色眼睛、耳鳍、蝠翼及红黑尾鳍；默认四足支撑，移动时四足错峰抬起。
- [ ] 沿左右、上下方向移动时身体面向移动方向，可看到正面、侧面和背面；转弯逐步转身，停下后移动鼠标不会把身体拉回正面，头部单独注视。
- [ ] 以不同速度观察四肢：肘膝有弯曲，抬脚后向前送、落脚后形成支撑，横向和纵向移动时着地脚均没有持续滑行；暂停时步态和转向一起停止。
- [ ] 卧躺与睡觉时头身明显下沉、四爪保持着地、耳翼收拢；警戒时头部抬起、竖耳展翼。动作切换及抚摸打断时没有瞬间跳变。
- [ ] 自由活动时把鼠标放在宠物附近约 95–175 像素，观察伏低蓄势、扑出、落地的完整过程；扑出后立刻移动鼠标，宠物仍按锁定轨迹完成动作，前进不超过 65 像素，不操作桌面内容。
- [ ] 扑食结束后 18 秒活动时间内不反复起扑；蓄势或腾起时抚摸、提起可打断。分别在扑食时暂停或隐藏，恢复后从原进度继续；靠近工作区角落起扑时模型不被裁切。
- [ ] 随机片段、躲闪或整理期间暂停、隐藏，再恢复后动作继续，不补播离开期间的动作；暂停时点击或拖动不会移动宠物。
- [ ] 温柔摸头累计约一分钟后，闲置一分钟再将鼠标移近，会短暂挥爪招呼；不会每次靠近都反复招呼。正常退出再启动后保留熟悉度和摸头偏好。
- [ ] 疲倦时仍可自主卧躺或睡觉，不再尝试回窝。分辨率变更后活动仍受工作区边界限制。
- [ ] 连续运行约一分钟，角色沿四边活动，无明显穿出工作区；当前为安全距离巡游，攀爬和接触动画待后续制作。
- [ ] 键盘空闲30秒后进入下述自动整理流程；鼠标活动不重置计时，图标从不被打开，文件路径不变。
- [ ] 新增、删除或拖动图标，约 10 秒后目标位置更新；隐藏桌面图标时检查是否仍取得隐藏视图的位置。
- [ ] Explorer 重启或图标读取失败时继续巡游，恢复后可重新读取；记录有无超时或资源泄漏。
- [ ] 分别通过右键菜单与 Ctrl+Alt+P 暂停/继续。
- [ ] 隐藏后使用 Ctrl+Alt+H 恢复；隐藏期间不遮挡桌面；Ctrl+Alt+Q 能退出。
- [ ] 检查全局快捷键冲突时是否输出错误并退出，不留下透明遮挡窗口。
- [ ] 改变分辨率、屏幕排列或接入/断开副屏后窗口与活动范围正确；调整任务栏位置后重启复测。
- [ ] 运行 30 分钟后记录 CPU、GPU、内存和是否持续增长，判断资源占用是否可接受。

## 长期陪伴补充验收

- [ ] 桌面不再出现小球和小窝，右键、编辑器及自主行为均无相关入口。

- [ ] 关系显示初识、熟悉或信任；温柔摸头逐渐增加关系，熟悉后有凑头反馈。使用独立测试目录验证阶段，避免篡改真实用户进度。
- [ ] 信任后鼠标稳定停留在附近约四秒，宠物偶尔靠近，在约 100 像素外趴下；移动鼠标或按键取消，不连续追逐。
- [ ] 亲近过程中暂停或隐藏，所有动作冻结，恢复后无离线补播；已有关系变化仍能自动保存。
- [ ] 在 100%、125%、150% 缩放下检查宠物的实际命中与拖动，其他桌面区域可点击且不抢焦点。
- [ ] 工作区和分辨率变化后宠物仍在安全范围，不沿旧扑跃或亲近轨迹跳回。
- [ ] 先备份真实数据，再验证旧 PlayerPrefs 和含物件位置的旧 JSON：关系正常恢复，新存档不再写入物件位置，旧键未删除，离线后精力心情恢复且关系保留。
- [ ] 自动保存成功后强制结束再启动能恢复进度；主文件损坏从备份恢复，双份损坏保留带 corrupt 后缀的原件；较新版本文件不被覆盖。

## 退出与日志

正常退出后不应残留进程或快捷键占用。Unity Windows 日志默认位于 `%USERPROFILE%/AppData/LocalLow/ElecPet/ElecPet Prototype/Player.log`。日志不包含桌面文件名称与完整路径。

## 自动整理桌面图标

真实写入验收使用指定的测试桌面或测试项目，先记录项目位置与网格设置；模拟检查和编辑器预览不替代下列实机项。

- [ ] 启动桌宠后无需点击菜单，键盘连续空闲30秒才开始；不足30秒、暂停、隐藏或被提起时不移动图标。期间持续移动鼠标、点击和滚轮都不重新计时。
- [ ] 按名称升序将前 12 个图标排成居中的对称空心爱心，多余图标从左上角向下逐列排，爱心内部保持留白；同名项目按稳定身份排序，扫描顺序变化不改变目标。
- [ ] 6–11 个图标沿对称轮廓分布；少于 6 个或工作区不足以容纳爱心时从左上角规整排列。改变分辨率或图标间距后重新规划，图标和文字单元不重叠、不越过任务栏。
- [ ] 宠物依次走近、低头叼起、四足搬运、放下，图标贴近嘴部；观察左右和纵向转身，起步与停步平滑，无图标副本或瞬移。
- [ ] 只有键盘输入重置30秒空闲门槛，普通鼠标移动或点击不暂停。手动移动、删除或增加图标后，源位置及阶段核对保护用户调整，重新规划有效任务。
- [ ] 抚摸或提起立即取消当前整理，图标停留在已确认的位置；互动结束后重新等待空闲。退出不会继续排队搬运。
- [ ] “自动排列图标”开启时保留原设置，菜单显示等待原因；关闭后自动重试。启用“与网格对齐”时测试搬运中的连续位置、暂停、结束及失败恢复，其他设置不变。
- [ ] 完成后继续空闲不反复搬动；新增项目只调整必要目标。满屏且无腾位空间时不叠放、不执行部分溢出计划。
- [ ] 检查工作区四边、任务栏移动、不同DPI和副屏：模型不裁切，主屏图标不越界，副屏图标保持原位。
- [ ] Explorer重启、COM失败或定位被系统拒绝时停止当前计划，原对象不复用，无持续刷屏告警；恢复后可低频重试。
- [ ] 整理前后项目名称与文件路径一致；记录实际帧率、CPU和Explorer负载，确认无明显卡顿。

## 点击小龙看图

- [ ] 开启屏幕陪伴，普通左键点击小龙并松开，立即开始观察当前有效窗口，不等待自动停留 30 秒；原有触碰动作保留，回复使用奶油白气泡。
- [ ] 快速短点击仍触发一次；按下后移动超过 6 像素并松手属于提起放下，松开帧才产生位移也不触发看图。
- [ ] 生成回复期间重复点击不叠加任务；模型能力检查期间点击一次，检查完成后接着观察。两次有效手动请求至少间隔 2 秒。
- [ ] 喂食、暂停、隐藏或屏幕陪伴关闭时不触发。切换窗口、标题或快速切走再切回后，不展示之前的结果；恢复后不补发被取消的点击。

## 文件喂食

真实文件验收仅使用专门创建且内容可确认的测试文件；原生接口检查与离线动画不替代完整的资源管理器手动拖放体验。

- [ ] 从资源管理器拖文件到宠物身上，三秒内松手或拖离均不操作文件；再次进入重新计时。普通按住鼠标、移动窗口和提起宠物不会启动文件喂食。
- [ ] 连续停留满三秒时显示“松手投喂”并张嘴等待，保持按住不会回收；松手才开始进食，文件代理进入真实口腔，随后咀嚼、吞咽、眯眼和摆尾。背向用户时松手后自然转向前方。
- [ ] 图片、视频和普通文件分别显示对应卡片，多选后逐个处理，每个文件只回收一次；只有确认回收成功才播放满足反馈，且可在系统回收站恢复。
- [ ] 暂停、隐藏或提起会取消尚未提交的文件和剩余队列；已提交的操作收取真实结果。等待结果时提起仍有四爪悬空动作，退出等待正在执行的回收完成。
- [ ] 文件夹、只读文件、网络路径和符号链接安全拒绝。容量不足的失败后原路径和内容保持；正常结束无 `.ElecPet-feed-*.guard` 残留，HTML 资源目录不被连带回收。
- [ ] 喂食时不被整理、抚摸、问候和旧扑跃抢占；喂食结束后恢复自主行为。检查不同 DPI、任务栏边缘和长时间运行时的提示与命中位置。

## 鼠标捡球互动

- [ ] 自由活动时鼠标进入约 175 像素范围，小龙停止散步，伏低、竖耳摆尾，头部随鼠标动态转动；缓慢移动不会出现球。
- [ ] 在蓄势后快速甩动鼠标至少约 90 像素并停稳，终点出现橙色球；小龙飞奔到球旁低头拾取。
- [ ] 捡球后继续移动鼠标，小龙叼球追随；靠近约 75 像素后固定落点，鼠标再移动也不改变本次落点。
- [ ] 展翼振翅、收爪绕飞两圈后落地，低头放球，小球缩小消失，恢复自主行为。
- [ ] 暂停、隐藏、提起、慢速抚摸和文件悬停打断时小球立即清理，恢复后不补播；整理和已有明确互动不被普通靠近抢占。
- [ ] 在任务栏、屏幕四边及副屏边缘抛球均使用安全位置；不连通屏幕导致无法前进时约 1.5 秒后取消，不永久占用自主行为。
